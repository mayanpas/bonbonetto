# ☕ Bonbonetto - Cafeteria Premium

Bem-vindo ao repositório oficial do website da **Bonbonetto**, uma cafeteria dedicada a proporcionar experiências sensoriais únicas através de cafés especiais e confeitaria artesanal de alta qualidade.

---

## 📖 Sobre o Projeto
Este projeto tem como objetivo desenvolver uma presença digital elegante e funcional para a Bonbonetto. Focamos em um design que reflita a sofisticação da marca, facilitando o acesso dos clientes ao nosso menu, história e informações de localização.

## ✨ Funcionalidades
* **Apresentação de Produtos:** Catálogo visualmente atraente de cafés e sobremesas.
* **Design Responsivo:** Experiência otimizada para dispositivos móveis, tablets e desktops.

## 🛠 Tecnologias Utilizadas
O projeto foi desenvolvido com tecnologias essenciais de front-end:

* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Estilização focada em elegância e responsividade.
* **JavaScript:** Interatividade básica para a melhor experiência do usuário.
